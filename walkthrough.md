# Earthquake Prediction & Detection System — Walkthrough

## Project Overview

A full-stack earthquake prediction system using **3 CSV datasets** and **5 ML models**, with a premium interactive frontend dashboard.

---

## Project Structure

```
earthquake prediction (ml)/
├── query.csv                    # USGS earthquake catalog (19,365 rows)
├── output.csv                   # NOAA significant earthquakes (4,090 rows)
├── eqint_tsqp.csv              # Macroseismic intensity reports (157,015 rows)

│   ├── __init__.py
```

## ML Models & Results

### Model 1: Magnitude Predictor
- **Dataset:** [query.csv](file:///d:/GRIND/projects/earthquake%20prediction%20(ml)/query.csv) (USGS catalog)
- **Target:** Earthquake magnitude
- **Features:** latitude, longitude, depth, gap, dmin, rms, temporal features, nst
- **Best Algorithm:** XGBoost (R²=0.34, RMSE=0.32)
- **Source:** [magnitude_predictor.py](file:///d:/GRIND/projects/earthquake%20prediction%20(ml)/src/models/magnitude_predictor.py)

### Model 2: Severity Classifier
- **Dataset:** [output.csv](file:///d:/GRIND/projects/earthquake%20prediction%20(ml)/output.csv) (NOAA significant EQ)
- **Target:** Severity level (Low / Medium / High / Catastrophic)
- **Features:** Mag, Depth, Location, MMI, Tsunami flag, Year
- **Best Algorithm:** Random Forest (Accuracy=67.7%, F1=0.65)
- **Source:** [severity_classifier.py](file:///d:/GRIND/projects/earthquake%20prediction%20(ml)/src/models/severity_classifier.py)

### Model 3: Intensity Predictor
- **Dataset:** [eqint_tsqp.csv](file:///d:/GRIND/projects/earthquake%20prediction%20(ml)/eqint_tsqp.csv) (157K intensity reports)
- **Target:** Modified Mercalli Intensity (MMI)
- **Features:** Magnitude, Depth, Epicentral distance, coordinates, interaction terms
- **Source:** [intensity_predictor.py](file:///d:/GRIND/projects/earthquake%20prediction%20(ml)/src/models/intensity_predictor.py)

### Model 3: Seismic Zone Clustering
- **Dataset:** query.csv (spatial coordinates)
- **Method:** K-Means with k=5, 7, 10
- **Source:** [clustering_analysis.py](file:///d:/GRIND/projects/earthquake%20prediction%20(ml)/src/models/clustering_analysis.py)

### Model 4: Time Series Analysis
- **Dataset:** query.csv (temporal patterns)
- **Analysis:** Monthly frequency, yearly aggregates, rolling averages, magnitude distributions
- **Source:** [time_series_analysis.py](file:///d:/GRIND/projects/earthquake%20prediction%20(ml)/src/models/time_series_analysis.py)

## Frontend Dashboard

The dashboard at [index.html](file:///d:/GRIND/projects/earthquake%20prediction%20(ml)/website/index.html) features:

| Section | Content |
|---------|---------|
| **Hero** | Animated seismic wave, stat counters (180K+ records, 8 models, 3 datasets) |
| **Dataset Explorer** | 3 glassmorphism cards with row counts, columns, completeness bars |
| **Global Map** | Interactive Leaflet.js map with 2,000 earthquake markers color-coded by magnitude |
| **Model Results** | 5-tab panel: Magnitude, Severity, Intensity, Clustering, Time Series |
| **Risk Analysis** | Top 10 risk regions (Indonesia #1), magnitude/depth distributions |
| **Footer** | Tech stack badges |

### Design System
- **Theme:** Deep navy/charcoal dark mode with glassmorphism
- **Colors:** Seismic red, tectonic blue, warning amber, success green
- **Typography:** Inter (body) + JetBrains Mono (data)
- **Animations:** Scroll-triggered fade-ins, animated counters, seismic wave SVG
- **Source:** [styles.css](file:///d:/GRIND/projects/earthquake%20prediction%20(ml)/website/css/styles.css)

## How to Run

```bash
# From project root:
python run_pipeline.py          # Runs all models, generates JSON

# Start the dashboard:
cd website
python -m http.server 8000      # Visit http://localhost:8000
```

> [!NOTE]
> The pipeline takes ~42 seconds to complete. All JSON results are saved to `website/data/`.
